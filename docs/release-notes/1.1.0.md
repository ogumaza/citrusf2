A release that converts Mighty Gunvolt Burst's music. No earlier release could. Game profiles also play some sounds of other games as each game's code sets them up. They write a file for each other state of those sounds. citrusf2 converts the sequences of Nintendo 3DS sound archives (`.bcsar`) to MIDI, SoundFont 2 and SFZ files. Convert an archive again to get the new files.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bcsar` files onto `citrusf2.exe`. You can also use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. citrusf2 builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **Mighty Gunvolt Burst.** The game plays each piece of its music as five sequences at once. Each sequence plays one channel of the NES's sound chip. citrusf2 now converts each piece to one MIDI file, one SoundFont and one set of SFZ files. The files take the piece's name, such as SEQ_MCR_BGM_01. The game keeps its sequences in group files (`.bcgrp`) outside the sound archive. Keep them beside the archive.
- **Group files.** citrusf2 now reads the group files that lie beside an archive. Some games keep sequences in them. An archive with no group file beside it converts as before.
- **Game profiles.** A game's code can set up a sound as it plays it. The code picks the tracks that sound and sets variables, the tempo, the pitch, the volumes, the banks or the random state. citrusf2 picks a profile by the SHA-1 of the sound archive. The profile plays such sounds as the game starts them. citrusf2 also writes a file for each other state that the game gives a sound, such as SEQ_BGM_MENU_game_select or SEQ_BGM_BATTLE1_hurry. In the MIDI files, the tracks that the game mutes keep their notes at CC11 0.
- **The games with a profile.** Mario Party: Island Tour, Mario Party: Star Rush, The Legend of Zelda: Ocarina of Time 3D, WarioWare Gold, Animal Crossing: New Leaf, Animal Crossing: Happy Home Designer, Tomodachi Life, Super Mario 3D Land and Mario Kart 7. StreetPass Mii Plaza has one. So do four of its add-on games: Ultimate Angler, Flower Town, Ninja Launcher and Mii Force. Three system titles have one too: System Settings, the Activity Log and Mii Maker. A profile applies only to the build of the sound archive that it was made for. "Sequence playback" in the README says what each profile plays.
- **Other builds.** An archive that looks like another build of a game with a profile gets a note. In that archive, a sequence that citrusf2 has no start for plays every track.
- **`--var` and `--seed`.** For a sound that a profile sets up, the profile's values replace the values that `--var` and `--seed` give for the same variables and random state.
- **DJ K.K.'s club.** Animal Crossing: New Leaf plays DJ K.K.'s music only in the club. The game puts a reverb on bus A there. It adds 0.4 to each track's send. With `--reverb`, citrusf2 now adds the same 0.4 to CC91. Without the option, those files stay the same.
- **Ends of finished sequences.** A finished sequence can make its last change long after its last sound has died away. When that change comes more than 10 seconds later, the conversion now ends where the sound dies away. It used to run on in silence to the last change.
- **Countdowns inside a loop.** A sequence that counts down between notes inside its loop could stop with a silent loop of one tick. citrusf2 now plays on and loops the outer pass.
- **The README.** "Sequence playback" describes each profile. "Differences from the game" lists the track volumes that the profiles set and the effects that more games put on the buses. The README also says how `--loops` plays the passes before the marked pass. The list of sfizz 1.2.3's quirks has a new entry: sfizz makes each decay and release last at least 6 ms.
- **The libraries.** citrusf2 now builds on seqlib 1.3.0, xsflib 1.8.0 and ntdlib 3.2.0.

## Known limitations

As in 1.0.8. A profile plays each sound in one of the game's states. No file changes its tracks, tempo or volumes as the game goes on. Any other archive plays every track of every sequence. See "Differences from the game" in the README for the full list.
