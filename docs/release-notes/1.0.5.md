A maintenance release. citrusf2 converts every archive to the same files as 1.0.4. The README corrects one figure and describes two more of the main loop's rules.

## Downloads

| File | Contents |
|---|---|
| `citrusf2-1.0.5-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bcsar` files onto `citrusf2.exe`. You can also use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. citrusf2 builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **SoundFont padding.** A sample's unrolled loop is followed by 32 samples, not 8 as the README said.
- **The main loop.** The README's account of the main loop gives two more of its rules. A sequence whose tracks all reach their end has no main loop. A tie or mono legato on a note below hearing changes nothing that can be heard.
- **The libraries.** citrusf2 now builds on seqlib 1.2.0, xsflib 1.3.0 and ntdlib 1.8.0.
