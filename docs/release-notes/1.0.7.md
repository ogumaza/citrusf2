A release that adds an option, `--reverb`, for games that put a reverb on effect bus A. citrusf2 converts the sequences of Nintendo 3DS sound archives (`.bcsar`) to MIDI, SoundFont 2 and SFZ files. Without the new option, citrusf2 converts every archive to the same files as 1.0.6.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bcsar` files onto `citrusf2.exe`. You can also use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. citrusf2 builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **`--reverb`.** The 3DS has two effect buses, A and B. A game's code can put an effect on each bus. Each track of a sequence has a send level for each bus. By default, citrusf2 reports the sends and keeps CC91 and CC93 at 0. A synth then adds no reverb or chorus. WarioWare Gold and The Legend of Zelda: Ocarina of Time 3D put a reverb on bus A. Pokémon X puts one there in the field. For such a game, `--reverb` writes each track's send A as CC91. CC91 is the synth's reverb send. A conversion with `--reverb` marks the same loops as one without it. Only the CC91 events differ.
- **The README on routing.** The README's "Routing", under "Differences from the game", says which effect each of these games puts on each bus. The Legend of Zelda: Majora's Mask 3D puts nothing on bus A. The section used to say that Pokémon X runs no effect on the buses.
- **Reports.** A conversion's report no longer says "SoundFont attenuated by 0.0 dB" for a cut too small to show. The files stay the same.
- **The libraries.** citrusf2 now builds on seqlib 1.3.0, xsflib 1.6.0 and ntdlib 1.13.0.

## Known limitations

As in 1.0.6. With `--reverb`, CC91 sends the notes to the player's reverb. That reverb doesn't sound like the reverb that the game runs. citrusf2 writes no send to bus B. MIDI has no controller for the delays that some games put there. See "Differences from the game" in the README for the full list.
