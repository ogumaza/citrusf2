A release that corrects the SoundFonts' levels in FluidSynth and BASSMIDI. In those players, each zone now plays at its full attenuation. The SFZ files follow the opcodes' documentation more closely. The MIDI files and samples stay the same. Convert an archive again to get the new SoundFonts and SFZ files.

| `citrusf2-1.0.6-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bcsar` files onto `citrusf2.exe`. You can also use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. citrusf2 builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **SoundFont attenuation.** FluidSynth, BASSMIDI and the E-mu chips apply 0.4 of a zone's initial attenuation. The specification calls for all of it. citrusf2 now writes 2.5 times each zone's attenuation in the generator. The generator's limit is 1440 cB. Those players play that limit as 57.6 dB. A modulator without a source contains any attenuation beyond 57.6 dB. FluidSynth 2.4.5 and later apply that modulator. BASSMIDI and earlier versions of FluidSynth ignore it. Attenuated zones used to play too loudly in those players. In the game, a region at volume 64 plays 6 dB below one at 127. FluidSynth used to play it 2.4 dB below. It now plays it 6 dB below. A player that follows the specification now plays every attenuated zone too quietly.
- **SoundFont pans.** Each instrument's global zone now contains a modulator from CC10 to pan with an amount of 500. It takes the place of the default modulator. The specification gives the default an amount of 1000. Every player surveyed applies it at 500. Pans therefore sound as before in those players. A player that follows the specification now pans as they do.
- **SFZ decays and releases.** The SFZ files now give decay and release times for the documentation's curve. That curve falls by a factor of e^-8 over the specified time: 69.49 dB. The times used to suit sfizz's fall of e^-9: 78.17 dB. Each time is now 8/9 of what it was. In a player that follows the documentation, decays and releases fall at the game's rate. sfizz 1.2.3 ends them sooner. Where the game has fallen 40 dB, sfizz has fallen 45 dB.
- **SFZ opcodes.** More opcodes keep to their documentation at sfzformat.com. Velocity ranges start at 1. A velocity of 0 is a note-off. Bend ranges are in whole cents. The filter curves move a cutoff in units of 9600 cents and a resonance in units of 40 dB. Those are the documented limits. A track of biquad type 5 moves its resonance in units of 50 dB. That goes beyond the documented limit. Each point of a curve gives the cutoff or resonance that it gave before. None of these changes can be heard.
- **A message.** The message for a sequence that an archive doesn't store no longer mentions a group file beside the archive. citrusf2 doesn't read such files.
- **The README on SFZ.** The SFZ section names sfizz 1.2 as the player tested. A new list gives the ways in which the opcodes depart from their documentation. The quirks of sfizz now include its faster fall of decays and releases.
- **The README on SoundFont players.** The README gives the two ways in which the SoundFont output departs from the specification: the zones' attenuation and the biquad low-pass's resonance. FluidSynth, BASSMIDI and the E-mu chips play a resonance of r dB as r - 3 dB at the cutoff. citrusf2 writes the resonance for those players. A player that follows the specification plays 3 dB more at the cutoff. The notes on tremolo, key groups and modulators now cover BASSMIDI and newer versions of FluidSynth.
- **The libraries.** citrusf2 now builds on seqlib 1.3.0, xsflib 1.5.0 and ntdlib 1.11.0.

## Known limitations

As in 1.0.5, apart from the changes above. A player that follows the SoundFont specification plays attenuated zones too quietly. sfizz 1.2.3 ends decays and releases sooner than the game. See "Differences from the game" in the README for the full list.
