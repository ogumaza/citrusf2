A release that comes closer to the game in loops and pitch. Looping players now repeat each loop at the right tempo. Inner loops, sweeps that fade below hearing and pitch LFOs that change during a note come out as the game plays them. A new `--voices` option drops notes as the game does when its voices run out. Convert an archive again to get the corrected files.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. The executable is now built with clang-cl instead of MSVC. Drop one or more `.bcsar` files onto `citrusf2.exe`, or use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. Linux and Intel Macs are no longer supported. citrusf2 now builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## New

- **`--voices N`** drops notes as the game does when all N voices are in use. A new note then takes the voice of the note with the lowest priority. That note stops. A new note of lower priority than every sounding note is dropped. The game has 24 voices unless it sets another count. Pokémon X sets 23. The result only approximates the game. citrusf2 doesn't model the voices that the console's DSP drops. A stolen note that shares its MIDI channel with other sounding notes keeps its MIDI release tail. citrusf2 reports such notes. By default, and with `--voices off`, citrusf2 keeps every note. 1.0.2 kept only the first 24 notes that a track started in one tick.

## Fixes

- **Loop tempo.** A tempo change on a loop's first tick now comes after the loop markers. A looping player used to skip it and repeat the loop at the tempo of the loop's end. Playback straight through doesn't change.
- **Inner loops.** A loop that a track runs inside a pass of another loop, such as a countdown of waits between notes, is an inner loop. The passes of an inner loop count only once the track has played no pass of another loop for 10 seconds. A sequence could loop on a pass of an inner loop. That pass was often a single silent tick. Such a sequence now loops on a pass of the outer loop.
- **Pitch LFOs that change during a note** play as pitch bends. Such a note goes on a MIDI channel of its own. The note's preset there has no LFO. The channel's pitch bends add the game's LFO value in each sound frame. These notes used to keep the LFO settings of their note-on. When no channel is left, the note still keeps them. citrusf2 reports such notes.
- **Sweeps below hearing.** A newer note on a MIDI channel no longer follows the sweep or pitch LFO of an older note that has faded below hearing. The newer note used to take the older note's pitch until the older note ended.
- **Negative waits.** In the game, a track that waits a negative number of ticks never goes on to its next command. A note or wait whose length comes from a variable set to -1 has that effect. citrusf2 now counts such a track as waiting forever. A sequence with such a track could run to the 15-minute limit. It now loops on another track's loop, or holds for 10 seconds after its last change.
- **Tied notes with new envelope settings.** On a legato, the game applies the track's envelope settings from the point that the note's envelope has reached. citrusf2 used to work out the note's level as if the settings had applied from the note's start. Such a note now starts its release from the game's level. Its sound lasts as long as in the game.
- **Controllers on channels without notes.** A track that switched to another MIDI channel and played no note there sent that channel's controllers and pitch bends to the track's first channel. A release tail that still sounded there could bend or change level. citrusf2 now leaves those events out.
- **One-shot waves whose pitch changes while they play** end in the sound frame where the console ends them. The 3DS's DSP reads a wave ahead of the sample it plays. The lead is the playback rate less one sample. citrusf2 used to take the lead from the rate at the wave's start. Each change of rate now moves the lead.
