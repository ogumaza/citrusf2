First release of citrusf2, a MIDI, SoundFont 2 and SFZ converter for Nintendo 3DS sound
archives (`.bcsar`). It executes sequences using the game's playback rules and records the
result. Each sequence gets a MIDI file and a SoundFont containing its instruments. SFZ output
supports game filters that SoundFont cannot reproduce.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more
`.bcsar` files onto `citrusf2.exe`, or use a terminal; `citrusf2 --help` lists the options.
Output goes in a folder beside each archive.

For macOS and Linux, follow the build instructions in the README. macOS builds include
`Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## What it does

- **Sequence playback.** Follows Pokémon X's sound player as reconstructed by 3SF, including
  variables, random arguments, calls, loops and tracks that start other tracks. Uses the
  game's timing and random generator, and marks the main loop in the MIDI output.
- **MIDI.** Each sequence track gets its own MIDI track and channel. Volume, pan, pitch bend,
  LFO depth, effect sends and filter changes become controllers.
- **SoundFont.** Each combination of instrument and track settings becomes a preset, with the
  game's samples, tuning, volumes, envelopes and loops. Output targets FluidSynth.
- **SFZ.** One file per sequence track, with low-pass, high-pass and band-pass filters and WAV
  samples. Output targets sfizz 1.2.
- **Archives.** Reads CSAR 2.x with PCM8, PCM16, DSP-ADPCM and IMA-ADPCM waves, including banks
  and wave archives stored in groups. An unreadable archive reports an error without stopping
  the remaining conversions.
- **Reports.** Lists approximations required by MIDI, SoundFont or SFZ for each sequence.

## Known limitations

- Streamed music and wave sounds are not converted.
- MIDI pitch bend applies to a whole channel. Game sweeps, portamento and legato key changes
  apply to individual notes.
- Legato needs a new MIDI note when velocity increases or envelope/LFO settings change. This
  restarts the sample and envelope instead of continuing the existing note as the game does.
- SoundFont provides one low-pass filter per voice. High-pass and band-pass are omitted, and
  the track low-pass is approximated. SFZ supports all of these filters.
- Synth interpolation differs from the 3DS DSP, mainly above 8 kHz, as does output limiting.
- IMA-ADPCM decoding has not been checked against a game.
- See "Differences from the game" in the README for the full list.
