A release that follows the game more closely: tied notes, glides, held notes, tremolos, release tails and loops now come out much as the game plays them, and a new `--var` option plays sequences that wait for the game. Convert an archive again to get the corrected files.

## Downloads

| File | Contents |
|---|---|
| `citrusf2-1.0.2-win-x64.zip` | Windows x64 executable, `README.md` and `LICENSE` |

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.bcsar` files onto `citrusf2.exe`, or use a terminal; `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS and Linux, follow the build instructions in the README. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## New

- **`--var N=V`** sets player variable N (0-15) or global variable N (16-31) to V before each sequence starts. Some sequences play nothing until the game sets one of their variables. Repeat the option for more variables, and use `--only` to choose the sequences.

## Fixes

- **Tied notes** continue when a tie or mono note raises their velocity. They used to restart their sample. A legato after an envelope reset continues too.
- **Notes with settings of their own** get another MIDI channel: release tails keep their settings, a new note's glide no longer bends older notes, and notes above velocity 127 play at their level.
- **Notes the game plays silently**, at velocity 0, leave the pitch and settings of other notes alone. A release tail used to follow a silent note's glide.
- **Notes that fade below hearing** count as silence. A tied melody that a subroutine repeats until the game stops the sound no longer gets loop markers once the melody has faded. A note without a length ends where its envelope has decayed 60 dB. A tie or mono legato on a note below hearing no longer starts a new note at full level.
- **Silent loops.** A main loop that starts no note gets no loop markers once the notes before it have ended. The sequence ends with its last sound, like one that finishes. Sound effects that wait in silence until the game stops them used to run to 10 seconds, with markers on the silence. A looping player never ended them. A sequence that plays no note at all now ends at once.
- **Glides** move in every sound frame between ticks, as in the game, and go on after their track closes.
- **Notes the game stops itself**, which a track waits out for minutes, end 10 seconds after the last change instead of playing for minutes.
- **Deep tremolos** no longer rise more than 6 dB above the note, the game's limit.
- **Notes released during a slow attack** start their release at the game's level. They used to start it far too loud.
- **Release tails** take the track's last settings when a tie, mono or mute command detaches them.
- **Loops.** The loop markers go on the first pass that a player looping on them repeats as the game plays the next, with the same notes, settings and tempo. The first pass often plays otherwise, and a looping player repeated it with wrong values or struck held notes again. Where only a later pass repeats, the file grows by that pass. At the loop's start, the MIDI file sends the values and tempo the game restores there. A track that only polls or counts a variable no longer makes a loop of a tick or two that cut the sequence short, and a sequence that ends no longer keeps a loop marker. A sound effect that plays once and then waits in a subroutine for the game now ends with its sound. It used to come out as a 10-second file that looped on silence.
- **LFO settings** made later in a note's tick reach the note.
- **Slow decays** are as far above the game's level at the end of their hold as below it later. That halves their largest error.
- **Random choices** match those of the 3SF project's model of the game.
- **Effect sends** no longer add reverb and chorus that the game doesn't play. The game's code determines whether its effect buses have an effect, and Pokémon X runs none. CC91 and CC93 stay at 0, and the sends are reported.
- **Notes above velocity 127** play through a bank's direct velocity table, as in the game. They used to play nothing.
- **SFZ files** apply volume, expression and pan changes at once, without sfizz's 10 ms smoothing. Like the game, they select a note's biquad filter from the end of its sound frame. Regions set to linear interpolation or none get it in sfizz.
- **Damaged archives.** An archive whose name table is damaged converts, with its sounds numbered. The warning for a truncated archive says what happens to its sounds, and a damaged group no longer warns about files that another group holds.
- **Citrusf2.app** adds its note on a truncated archive only when something converted.
