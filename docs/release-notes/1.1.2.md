citrusf2 now writes the reverb send of the games known to put a reverb on effect bus A by default, and it converts two more states of StreetPass Mii Plaza's Find Mii II.

Requires 64-bit Windows 10 or later. No additional runtime DLLs are required. Drop one or more `.bcsar` files onto `citrusf2.exe`. You can also use a terminal. `citrusf2 --help` lists the options. Output goes in a folder beside each archive.

For macOS on Apple Silicon, follow the build instructions in the README. citrusf2 builds on three libraries in Git submodules. Clone the repository with `--recursive`. macOS builds include `Citrusf2.app`. Drop archives onto the app in Finder to convert them.

## Changes

- **The reverb send by default.** For a game whose code citrusf2 has a profile of, and that puts a reverb on effect bus A, each track's send A now becomes CC91 by default. Before, only `--reverb` wrote it. A sound that the game plays with no reverb on bus A keeps CC91 at 0. Flower Town's `SOUNDLIST_` pieces are such sounds: only StreetPass Mii Plaza's sound test plays them, and it plays them dry. `--reverb` now decides only for the games whose effects citrusf2 has no profile of. Only the CC91 events change. The loops stay where they were.
- **Find Mii II's walls.** Behind a wall of fire or poison, StreetPass Mii Plaza plays the room's battle piece quieter and muffled. citrusf2 now also writes the two battle pieces in that state, BGM_DEN2_Battle01_wall and BGM_DEN2_Battle02_wall, with the game's low-pass on every track.
- **Ninja Launcher.** SEQ_JIN_NOTICE and SEQ_JIN_UPDATE send 0.15 to bus A, as the game's play routine sets it. Their CC91 now follows.
- **Sequence names.** In an archive without a string block, or with a damaged one, a sequence now takes its name from a label in its sequence file where it can, in place of SEQ_0, SEQ_1 and so on. The warning on a damaged name table says so. The files of those sequences are otherwise the same.
- **Messages.** The note on another build of an archive that citrusf2 has a profile of now comes after the archive's warnings, not before them. An archive that fails to load gets no note.
- **The libraries.** citrusf2 now builds on seqlib 1.5.0, xsflib 1.12.0 and ntdlib 7.0.0.
